# 돌려본 것들

운영에서 겪을 법한 장애를 하나씩 골라 **규칙 하나만 남긴 최소 형태로 재현**하고,
막을 방법들을 같은 조건에서 나란히 재본 기록. 프론트엔드·데이터베이스·JVM·Rust·보안 실험 17편.

**→ https://kzhxxn.github.io/engineering-lab/**

## 무엇이 다른가

여기 있는 숫자는 인용이 아니라 실제로 돌려서 나온 값이다. 그리고 각 글은
**원인 설명에서 끝나지 않는다.** 후보들을 같은 조건에서 재고, 무엇을 고를지의
기준과 그 선택의 비용까지 적는다.

실무에서 겪은 상황을 가져온 글은 **당시 판단과 지금 재본 것을 글머리에서 구분**해 둔다.
그때 알았던 것과 이번에 재보고 알게 된 것은 다르고, 그 차이를 지우면 글이 과장된다.

| 마주치는 상황 | 확인한 것 |
|---|---|
| 토큰을 브라우저에서 숨기려면 어디까지 옮겨야 하나 | 모아도 갱신이 **N번**. 합쳐야 1번, 인스턴스 늘면 다시 갈라짐 |
| 한글만 깨지는데 영문 테스트는 다 통과한다 | 영문에서는 수정 전후 **차이 0**. 그래서 못 잡는다 |
| 보장 한도를 넘겨 지급됐는데 잘못 승인된 건이 없다 | 막는 방법 **11가지**를 재봤고, 통념 둘이 틀렸다 |
| CI는 초록불인데 운영에서만 숫자가 안 맞는다 | 같은 코드가 **100만 회 30/30 실패, 1천 회 0/20 실패** |
| 인덱스를 만들었는데 쿼리가 그대로다 | 비용 모델을 **오차 0.00%로 재현**하고, 식을 뒤집어 이 환경의 `random_page_cost`를 되찾았다. 기본값은 7개 중 5개를 틀리고 역산값은 0개 |
| 힙을 늘렸는데 또 OOM으로 죽는다 | **500MB는 통과하고 14MB에서 죽는다.** 총량이 아니다 |
| 커밋 응답을 받았는데 서버가 죽으면 | WAL 복구 시작 LSN이 크래시 직전 기록과 일치 |
| 목록 API가 DB를 스물한 번 호출하고 있었다 | 쿼리 수 = **1 + N** 정확히. 조인은 언제나 1 |
| 식별번호를 암호화해 보내랬는데 어디까지 바꿔야 하나 | ECB를 피해도 **2/3 블록이 그대로 샌다.** 고칠 건 IV였다 |
| 실재하지 않는 번호인데 검증을 통과했다 | 무작위 번호 **9.99% 통과**. 대신 오타는 90~100% 잡는다 |
| 버튼을 잠갔는데 같은 결제가 여러 번 생겼다 | 방어 **6가지 중 막은 건 2가지**. 셋은 얹혀만 있었다 |

### 틀린 것으로 드러난 통념

- **"불변식은 DB 제약으로 옮기면 된다"**. 못 막는다. 제약 트리거가 `count(*)`를 세는데
  그 `SELECT`도 자기 스냅샷에서 돈다. 둘 다 "1명 남네" 하고 통과시킨다.
- **"쓰기 직전에 재확인하면 된다"**. 못 막는다. 재확인도 읽기라 락이 없으면 상대를 못 본다.

### 재현하지 못한 것도 남겼다

명령어 재배열(JMM reordering)은 3,000회를 시도했지만 한 번도 관측하지 못했다.
`synchronous_commit=off`에서 데이터가 실제로 유실되는 장면도 만들어내지 못했다.
둘 다 그 사실을 지우지 않았다.

## 인터랙티브 데모 8종

슬라이더와 토글로 직접 조건을 바꿔볼 수 있다. **값은 전부 실측치이고, 재보지 않은
구간은 만들어내지 않았다.** 측정한 지점만 오간다.

| 데모 | 조작해볼 것 |
|---|---|
| write skew | 격리 수준(RR ↔ SERIALIZABLE) · 두 트랜잭션의 겹침 정도 |
| 레이스 컨디션 | 스레드당 반복 횟수. 어디서 "테스트가 통과"하기 시작하는지 |
| N+1 | 팀 수 N · 로딩 전략 3종. 쿼리가 몇 번 나가는지 |
| 인덱스 전환점 | 선택도 0.1~50% · bitmapscan on/off · 강제 계획 비교 |
| SSR 인증 | 동시 요청 수. 토큰 갱신을 어디에 맡기면 몇 번 나가는지 |
| IME 조합 | 한글/영문 전환. 영문에서 왜 차이가 0이 되는지 |
| 이해 게이트 | **퀴즈 5문항.** 전부 맞히면 완료 코드가 열린다 |

## 기술적 제약

의존성 0. 단일 HTML 파일 하나에 CSS·JS·SVG가 전부 인라인으로 들어 있고,
CDN도 웹폰트도 불러오지 않는다. 저장해서 오프라인에서 열어도 그대로 동작한다.
라이트/다크 테마 모두 대응한다.

```
git clone <이 저장소> && open index.html
```

빌드 단계가 없다.

## 실험 환경

PostgreSQL 16.15 (Docker) · Java 17 (Zulu, `javac`만 사용, 빌드 도구 없음) · Rust 1.98.1 ·
Apple Silicon macOS. 벤치마크는 `jit=off` 고정, 시간 값은 5회 중앙값.
